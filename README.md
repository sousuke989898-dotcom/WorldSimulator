# Unity Grid-Based Fluid Simulation (Sandbox)

Unity 6 LTSのサンドボックスRPG向けに開発した、軽量かつ安定したグリッドベースの水流シミュレーションシステムです。

## 🎯 概要と特徴
ゲームとしての快適な動作と自然な見た目を両立させた「セルベースの分散配分モデル」を採用しています。

* **3層レイヤー構造**: `HeightMap`（地形）、`WaterMap`（水量）、`WaterFlowMap`（慣性）によるシンプルで軽量なアーキテクチャ。
* **4方向独立比率配分モデル**: 水面（地形＋水量）の高低差をベースに、周囲4方向へ水と慣性を自然に分散・枝分かれさせることで、水たまりや川の氾濫をリアルに表現。
* **慣性バイアスと切り捨て対策**: 前フレームの流速ベクトル（内積）による方向ボーナスを付与し、水の慣性を実装。
